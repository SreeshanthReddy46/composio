"Where the Agent Failed / Apps That Beat Me"

True integration research reveals that certain edge cases actively defy standard automated scraping. Below are four archetypes that required human triage:

WhatsApp Business (Meta BSP)

Failure: Extractor marked self-serve as unknown. Reality: Requires Meta Business Verification and template pre-approval. Pure HTTP scraping cannot verify organizational onboarding gates.

NotebookLM (Closed App)

Failure: Extractor attempted to find an API endpoint. Reality: Zero public developer API exists; web application UI only. The agent had to be taught to return clean blocked verdicts.

Amazon SP-API (AWS SigV4)

Failure: Extractor struggled to categorize auth. Reality: Hybrid architecture: Login with Amazon (LWA) OAuth token combined with AWS Signature Version 4 IAM signing.

Sherlock (CLI Tool)

Failure: Extractor searched for HTTP endpoints. Reality: Open-source command-line OSINT tool without a SaaS cloud backend. Correctly classified as skill_or_cli_only.
